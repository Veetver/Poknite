# Poknite

Лёгкая система текстовых уведомлений с собственным сервером и клиентами для Android, Windows и Linux. Устройства подключаются напрямую по HTTPS/WSS. Внешние push-службы и отдельный сервер баз данных не нужны.

Poknite предназначен для небольших групп — по умолчанию до 20 пользователей и 60 устройств. Интерфейс на русском языке. Проект распространяется под [лицензией MIT](LICENSE).

## Возможности

- Каналы, роли с приоритетом запретов и личные диалоги двух собеседников.
- Упоминания с адресными уведомлениями и текстовые сообщения до 4 КиБ.
- Уникальные изменяемые ники, случайный постоянный цвет и переназначение RGB.
- Нативное управление пользователями, каналами и ролями из доверенной LAN/VPN.
- Одноразовые приглашения и отдельный отзываемый токен для каждого устройства.
- Системные уведомления, фоновый приём и режим без звука.
- Восстановление пропущенных сообщений после переподключения.
- Ограниченное хранение на сервере и независимая локальная история.
- Один серверный процесс, встроенная SQLite и ограниченные очереди.

## Платформы

| Компонент | Требования | Технологии |
| --- | --- | --- |
| Сервер | Ubuntu 24.04, действующий TLS-сертификат | Rust, Tokio, Axum, SQLite |
| Настольный клиент | Windows 10/11 с Visual C++ Runtime x64 или Linux с X11/XWayland | Rust, FLTK |
| Android | Android 8 или новее | Kotlin, стандартные Views, OkHttp, SQLite |

Версия 0.2 находится на ранней стадии. Доставка Android в фоне зависит от ограничений ОС и производителя; для неё используется foreground service с постоянным уведомлением.

## Начало работы

1. Скачайте готовые файлы из [последнего релиза](https://github.com/Veetver/Poknite/releases/latest). Выберите файл для своей платформы по [инструкции установки](docs/installing.md). APK уже подписан; самостоятельно собирать программу и создавать ключ подписи не нужно.
2. [Установите сервер](docs/server.md) на Ubuntu с доступным по интернету HTTPS-адресом.
3. Создайте пользователя и отдельное приглашение для каждого устройства:

   ```sh
   sudo -u poknite poknited --config /etc/poknite/poknite.toml user 'Анна'
   sudo -u poknite poknited --config /etc/poknite/poknite.toml invite 1
   ```

   Подставьте ID пользователя, выданный первой командой. Приглашение действует 15 минут.

4. Установите и откройте [настольный](docs/desktop.md) или [Android-клиент](android/README.md), укажите адрес сервера и приглашение. Выберите канал, подключите ключ через «Шифрование» по [инструкции E2EE](docs/e2ee.md) и отправьте сообщение.

Если сервер уже настроен администратором, установите только клиент и получите у него адрес сервера и приглашение. [Сборка из исходников](docs/building.md) нужна для разработки или собственных изменений.

## Хранение и конфиденциальность

По умолчанию сервер выдаёт сообщения в течение 24 часов. Истёкшие сообщения нельзя восстановить с сервера, но уже полученные копии остаются на устройствах. Локальная история ограничена 1000 сообщениями и основной базой 8 МиБ; её можно очистить в клиенте.

Основная серверная база ограничена 32 МиБ. При заполнении отправка завершается ошибкой; действующие сообщения сохраняются до окончания срока хранения. Журналы и временные файлы SQLite учитываются отдельно. Настройки и обслуживание описаны в [руководстве сервера](docs/server.md).

Новые сообщения в каналах и личных диалогах защищаются сквозным шифрованием. Для каждого разговора доверенные участники подключают общий случайный ключ, который хранится только на устройствах. Сервер получает шифротекст. Код ключа переносится вручную через личную встречу или другой защищённый канал; приглашение сервера не заменяет ключ. Порядок подключения и ограничения описаны в [руководстве E2EE](docs/e2ee.md).

Сервер видит метаданные доставки. Старые открытые сообщения и резервные копии не становятся зашифрованными после обновления. Локальная история хранится открытым текстом и защищается правами доступа устройства. Без сети клиент сохраняет черновик; отправка после подключения выполняется пользователем.

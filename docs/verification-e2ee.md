# Проверки сквозного шифрования — 3 октября 2026

Проверено рабочее дерево разработки 0.2.0. Сборки не опубликованы; рабочий сервер пользователя не обновлялся. Все сетевые испытания используют отдельные временные базы, профили и приглашения.

## Выполнено

- Rust: 40 тестов workspace, форматирование и clippy всех целей без предупреждений. После добавления варианта JSON Android отдельно повторены тест совместимости и clippy клиентского crate.
- Серверный интеграционный тест: личные диалоги и каналы, отказ открытой отправке по умолчанию, только шифротекст в SQLite, HTTP-повтор, WSS-восстановление, отказ устаревшему составу устройств и недоступность нового ключа исключённому участнику.
- Независимые Python AES-GCM/JWE векторы: Rust и Android шифруют/расшифровывают общий формат. Проверены оба варианта записи защищённого JSON: Android экранирует `/`; клиенты используют исходные байты заголовка при проверке подлинности.
- Linux release через проверенные HTTPS/WSS: три устройства, локальный перенос ключа, доставка, восстановление отключённого устройства, истечение серверной копии с сохранением локальной, отзыв устройства и отказ недоверенному сертификату.
- Linux GUI в отдельном Xvfb: открытие «Шифрование», показ и импорт кода, получение в открытом и скрытом окне, повторный запуск, поиск, черновики и отправка в восстановленный разговор. Снимки и отчёт не содержат кода ключа.
- Android: JVM-тесты, lint, release/debug APK и instrumentation APK. На программном эмуляторе Android 15/API 35 выполнены 3 E2EE-теста и 8 тестов хранилища/интерфейса. Проверены сохранение ключа средствами Android Keystore, перезапуск, отсутствие ключа, раскрытие сохранённой истории после импорта, повторы и смена состава устройств.
- Android live-server: отдельный сервер с обязательным E2EE, два свежих пользователя и приглашения. Зашифрованная отправка, WSS-получение и системное уведомление после закрытия Activity, затем отзыв устройства прошли. HTTP/WS используются только в изолированном debug loopback через ADB reverse; отдельный Linux-прогон проверяет HTTPS/WSS.
- Проверки публичного/административного TLS, адреса управления, CIDR и замены сертификата прошли. Синтетический TLS-сценарий явно использует открытые тестовые сообщения; клиентский сценарий требует E2EE.

Размеры release: сервер 3,728 МиБ, Linux-клиент 4,668 МиБ, неподписанный APK 0,213 МиБ. RSS Linux GUI: 16,52 МиБ с окном и 16,53 МиБ в фоне; CPU за 5 секунд ожидания — 0,00 с. Это короткий локальный замер, не суточное измерение.

## Ограничения проверки

Windows/DPAPI, физический Android-телефон, Doze, батарея, пользовательский Linux desktop и суточная работа не проверены в этом прогоне. Программный эмулятор не подтверждает фоновые гарантии физического устройства. Независимый аудит криптографического протокола и клиентов не выполнялся.

В этой версии участники вручную переносят общий ключ разговора. Нет отдельных подписей устройств и forward secrecy. Смена ключа и потеря устройств описаны в [руководстве E2EE](e2ee.md).

Основные отчёты текущего локального прогона находятся в `/tmp/poknite-e2ee-qa/`: `client.json`, `gui.json`, `android-e2ee.txt`, `android-storage-ui.txt`, `android-delivery.txt`, `management.json`, `tls.json`. Они содержат только результаты изолированных испытаний.

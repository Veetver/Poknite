# Проверки разработки 0.2.0 — 3 октября 2026

Этот отчёт описывает проверки до добавления E2EE. Последующие проверки шифрования и выполненные на эмуляторе Android тесты приведены в [отдельном отчёте](verification-e2ee.md).

Среда: Linux x86_64, kernel 7.0.0-34-generic, glibc 2.43, Rust 1.99.0, Android SDK 37, release без отладчика. Это проверка рабочего дерева; опубликованного тега/выпуска нет.

## Выполнено

- Rust: 34 теста workspace; clippy всех целей без предупреждений; форматирование; release-сборка.
- Три изолированные проверки Linux D-Bus: уведомления, отсутствие службы трея, регистрация/активация/очистка трея.
- Android: JVM-тесты, lint, release/debug APK и сборка instrumentation APK. Добавлены тесты миграции/цвета/адресных уведомлений.
- HTTPS/WSS: CA и имя проверяются, ошибочная CA/имя отвергаются; замена сертификата сохраняет поток, некорректная замена не применяется; отзыв устройства закрывает поток.
- Отдельный административный TLS: CIDR фактического peer, отказ с подставленными IP-заголовками, admin отсутствует на публичном сервисе, отдельный IP клиента сохраняет TLS-домен, сбой управления не нарушает публичный HTTPS.
- Linux GUI в Xvfb с Xft: русский текст, цвет автора в истории, RGB профиля и палитра; получение в скрытом окне и открытие существующего экземпляра. Xvfb не заменяет сеанс пользовательского рабочего стола.
- 60 устройств, 60 секунд, 12 отправок / 720 доставок: 0 пропусков, 0 дублей, p95 0,701 с. Начальный RSS сервера 7,36 МиБ, максимум 7,87 МиБ; CPU 3,04 с. Это короткий локальный прогон, не суточная или интернет-проверка.
- Linux GUI после включения Xft: RSS с открытым окном и в фоне 15,70 МиБ, 0,00 с CPU за 5 с ожидания; получение в фоне и повторный запуск подтверждены.
- Настоящий ENOSPC в отдельном Docker tmpfs 512 КиБ: 19 сообщений по 4096 байт сохранены; отказ `507 storage_full`, повтор существующего UUID `200`, чтение и восстановление WSS работают, SQLite integrity `ok`. Диск хоста не заполнялся.
- Диагностика без приглашения `https://pinky.fvds.ru`: DNS разрешается, HTTPS-сертификат/имя проходят проверку, WSS возвращает ожидаемый запрос токена; сервер пока использует API v1. Проверка выполнена на Linux.
- Размеры после обновления интерфейса: сервер 3,69 МиБ, Linux-клиент с Xft 4,35 МиБ, неподписанный release APK 0,21 МиБ. Все меньше соответствующих лимитов; подписанный выпуск APK здесь не создавался.

## Интерфейс общения и последний выбранный разговор

На Windows/Linux добавлены боковой список с поиском, заголовок разговора, отдельное поле ввода, кнопки упоминания и возврата к последним сообщениям, отправка по Ctrl+Enter без добавления новой строки. Android получил отдельную прокрутку истории, сообщения с автором/временем и поле ввода внизу с учётом клавиатуры.

Выбор сохраняется на устройстве по ID, включая личные диалоги. Тест хранилища заново открывает SQLite и проверяет выбранный второй канал, сохранность двух черновиков, переименование/закрытие, пустой список, потерю доступа, очистку истории и сброс подключения.

Повторный `tools/client_smoke.py --gui-report /tmp/poknite-qa/chat-ui.json` прошёл на финальной release-сборке: поиск и переключение двух каналов сохраняют черновики; после полного завершения процесса открывается второй канал; восстановленный черновик отправляется именно в него по Ctrl+Enter с точным совпадением текста. Проверены также получение в открытом/скрытом окне и повторное открытие работающего экземпляра. RSS 15,91 МиБ с открытым окном и в фоне, 0,00 с CPU за 5 с ожидания. Снимок `/tmp/poknite-qa/chat-ui.png` содержит только тестовые данные.

Android повторно прошёл JVM-тесты, lint, release-сборку и сборку instrumentation APK. Добавлен UI-тест переключения черновиков, нового запуска Activity с восстановлением второго канала и перехода на доступный канал после удаления прежнего. Он скомпилирован, но не выполнен на устройстве; ограничения ниже сохраняются.

## Не подтверждено

Первоначальная ошибка Windows не воспроизведена: Windows-хост недоступен. Проверки Windows 10/11, DPAPI, трея и системных уведомлений должны выполняться на этой платформе, включая указанную диагностику. CI содержит сборку Windows, но запуск удалённого CI в этой работе не выполнялся.

Android instrumentation/UI не запускались: изолированный программный эмулятор без KVM не вышел в рабочее состояние; он остановлен, пользовательский AVD не изменялся. Физический телефон, Doze/фоновые уведомления, PSS и батарея также не проверены.

Суточная стабильность, реальные LAN/VPN-маршруты и firewall инфраструктуры, суточные замеры батареи и интернет-задержка остаются проверками перед общим выпуском. Локальные сборки не опубликованы; сервер пользователя не обновлялся.

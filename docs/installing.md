# Установка готового релиза

Откройте [последний релиз Poknite](https://github.com/Veetver/Poknite/releases/latest)
и скачайте нужный файл из раздела **Assets**. Для установки готовых сборок Rust,
Gradle, Android SDK и исходники проекта не нужны.

| Платформа | Файл | Что внутри |
| --- | --- | --- |
| Ubuntu 24.04, x86_64 | `poknite-<версия>-linux-x64.tar.gz` | Сервер `poknited`, настольный клиент `poknite`, файлы установки, документация и лицензии |
| Windows 10/11, x64 | `poknite-<версия>-windows-x64.zip` | Настольный клиент `poknite.exe`, документация и лицензии |
| Android 8 и новее | `poknite-<версия>-android.apk` | Готовый подписанный APK для установки |
| Android: полная поставка | `poknite-<версия>-android.zip` | Тот же APK, инструкция и лицензии; используйте при дальнейшем распространении |

Архивы **Source code (zip)** и **Source code (tar.gz)** содержат исходники.
Чтобы установить готовую программу, скачайте файл `poknite-…` из таблицы.

Примеры ниже приведены для версии 0.1.0. Если устанавливаете другую версию,
замените `0.1.0` в имени файла на номер скачанного релиза.

## Linux: сервер и настольный клиент

Распакуйте скачанный архив и перейдите в его каталог:

```sh
tar -xzf poknite-0.1.0-linux-x64.tar.gz
cd poknite
```

Для сервера нужны доступный HTTPS-адрес и TLS-сертификат с закрытым ключом.
Выполните [установку и настройку сервера](server.md) из распакованного каталога.
Для сервера без настольного клиента библиотеки X11 не требуются.

Для настольного клиента установите системные библиотеки и разместите готовый файл:

```sh
sudo apt install libx11-6 libxext6 libxft2 libxrender1 libxfixes3 libxcursor1 libxinerama1 libxrandr2 libdbus-1-3
mkdir -p ~/.local/bin
install -m 0755 ./poknite ~/.local/bin/poknite
~/.local/bin/poknite
```

Клиент использует X11; в сеансе Wayland нужен XWayland. Подключение и работа
с уведомлениями описаны в [руководстве настольного клиента](desktop.md).

## Windows

1. Установите [Microsoft Visual C++ v14 Redistributable x64](https://aka.ms/vc14/vc_redist.x64.exe), если он ещё не установлен. Это системные библиотеки для запуска клиента; подробнее — в [документации Microsoft](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).
2. Скачайте `poknite-0.1.0-windows-x64.zip`.
3. Выберите «Извлечь всё» и распакуйте архив в постоянный каталог.
4. Откройте каталог `poknite` и запустите `poknite.exe`.
5. Введите HTTPS-адрес сервера, одноразовое приглашение и имя устройства.

Для установки системных библиотек Windows может запросить права администратора;
сам клиент запускается без них. Автозапуск включается в настройках;
после его включения сохраняйте программу в том же каталоге.
Подробности — в [руководстве настольного клиента](desktop.md).

В текущих релизах Windows-клиент не имеет Authenticode-подписи издателя, поэтому
Windows может показывать предупреждение при запуске скачанной программы.
Подпись GitHub позволяет отдельно проверить происхождение архива.

## Android

1. Скачайте `poknite-0.1.0-android.apk` на телефон и откройте файл.
2. Если Android запросит разрешение, разрешите установку из этого источника
   для браузера или файлового менеджера, которым открыли APK.
3. Установите приложение и откройте Poknite.
4. Введите HTTPS-адрес сервера, приглашение и имя устройства. Разрешите уведомления
   и включите «Приём».

APK в Releases уже подписан постоянным ключом проекта. Дополнительная подпись
или создание собственного ключа для установки не нужны.
Настройки фонового приёма описаны в [руководстве Android](../android/README.md).

## Обновление клиентов

Для Windows и Linux завершите клиент через «Выход», затем замените исполняемый
файл готовой сборкой новой версии в том же каталоге и запустите его.
Профиль и история хранятся отдельно от программы и сохраняются при замене файла.

Для Android откройте APK следующего релиза и подтвердите обновление существующего
приложения. Удалять старую версию не нужно. Если установленный APK ранее был
подписан вашим собственным ключом, он не обновится APK из Releases как та же установка.

## Проверка подписей

В каждом релизе есть `SHA256SUMS` и `attestation.sigstore.json`.
Файлы Linux, Windows и Android имеют проверяемые GitHub attestations;
APK также содержит собственную подпись Android.

При установленной актуальной GitHub CLI можно проверить скачанный файл:

```sh
gh attestation verify poknite-0.1.0-linux-x64.tar.gz \
  --repo Veetver/Poknite \
  --bundle attestation.sigstore.json \
  --cert-identity 'https://github.com/Veetver/Poknite/.github/workflows/release.yml@refs/tags/v0.1.0'
```

Для Windows-архива или APK замените имя файла. Для другой версии также замените
номер тега в `--cert-identity`. Подробнее — в [инструкции проверки релизов](releases.md#проверка-скачанного-релиза).

# Настольный клиент

Скачайте готовый клиент из [последнего релиза](https://github.com/Veetver/Poknite/releases/latest): `poknite-<версия>-linux-x64.tar.gz` для Ubuntu 24.04 на x86_64 или `poknite-<версия>-windows-x64.zip` для Windows 10/11 на x64. Самостоятельная сборка не требуется; выбор файлов и проверка подписей описаны в [инструкции установки](installing.md).

Linux: распакуйте архив и перейдите в каталог `poknite`. Установите системные библиотеки, разместите клиент в постоянном каталоге и запустите его:

```sh
sudo apt install libx11-6 libxext6 libxft2 libxrender1 libxfixes3 libxcursor1 libxinerama1 libxrandr2 libdbus-1-3
mkdir -p ~/.local/bin
install -m 0755 ./poknite ~/.local/bin/poknite
~/.local/bin/poknite
```

Сборка использует X11; в сеансе Wayland нужен XWayland. Для уведомлений необходима обычная пользовательская D-Bus-служба уведомлений рабочего стола. Трей использует StatusNotifierItem, когда окружение поддерживает его; нажатие открывает окно, контекстное меню предлагает открыть окно или выйти. В окружениях без такого трея клиент доступен повторным запуском.

Windows: установите [Microsoft Visual C++ v14 Redistributable x64](https://aka.ms/vc14/vc_redist.x64.exe), если он ещё не установлен, затем распакуйте весь архив в постоянный каталог и откройте `poknite.exe`. Если система сообщает об отсутствии `VCRUNTIME140.dll`, установите этот пакет системных библиотек. Клиент создаёт системные уведомления через Windows API и значок в трее; двойной щелчок открывает окно, меню позволяет открыть окно или выйти. Для текущего пользователя создаются ярлык Poknite в меню «Пуск» и регистрация открытия окна из уведомления, без администратора. Ярлык содержит идентификатор приложения согласно [требованиям Microsoft для desktop-уведомлений](https://learn.microsoft.com/en-us/windows/win32/shell/enable-desktop-toast-with-appusermodelid).

Введите адрес HTTPS, приглашение и имя устройства. Выберите канал, напишите текст и нажмите «Отправить». Крестик скрывает окно, приём продолжается; «Выход» завершает процесс. Повторный запуск открывает существующий экземпляр. Автозапуск включается в настройках и привязан к текущему пути исполняемого файла. При переносе файла отключите и снова включите автозапуск.

Настройка «Без звука» оставляет видимые уведомления. Сообщения своего пользователя не вызывают уведомление. После восстановления истории появляется одно сводное уведомление. Вне сети сохраняется черновик; отправьте его самостоятельно после подключения. Неопределённый результат отправки повторяется с прежним ID, предотвращая дублирование в пределах серверного срока.

Linux хранит профиль с токеном в закрытом пользовательском каталоге, Windows шифрует токен средствами DPAPI. Локальная история хранится открытым текстом и защищается правами каталога. Сторонние пользователи устройства не должны иметь доступ к нему.

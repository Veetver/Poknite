Poknite 0.2.0 добавляет личные диалоги, управление пользователями и каналами и базовое сквозное шифрование новых сообщений на Windows, Linux и Android.

### Что изменилось

- Сквозное шифрование личных диалогов и каналов: ключ создаётся на устройстве, сервер хранит только шифротекст. Доставка после отключения и локальная история сохраняются.
- Раздел «Шифрование» позволяет создать, сменить и перенести ключ разговора между доверенными устройствами. Код ключа передаётся через личную встречу или другой защищённый канал.
- Личные диалоги, контакты, роли и разрешения, управление через отдельный HTTPS-адрес с ограничением доступа по LAN/VPN.
- Настройка ника и RGB-цвета, упоминания с адресными уведомлениями.
- Обновлённый интерфейс общения, поиск разговоров, отдельные черновики, восстановление последнего выбранного разговора и отправка по Ctrl+Enter.
- Диагностика HTTPS/WSS и сертификатов, улучшения настольных уведомлений и трея.

### Обновление с 0.1.0

Обновите сервер и все клиенты совместно: API v1 требует обновления. Сервер сохраняет резервную копию базы перед миграцией; ID пользователей и токены сохраняются. Android APK подписан тем же постоянным ключом проекта и устанавливается поверх прежней версии.

Перед первой отправкой выберите разговор и подключите ключ в «Шифровании». При добавлении или отзыве устройства либо изменении состава участников создайте новый ключ и передайте его оставшимся доверенным участникам. Приглашение сервера не содержит ключей разговоров.

Администратор без ключа разговора не может прочитать новые сообщения. Сервер по-прежнему видит участников, автора, время, размер сообщения и адресатов упоминаний. Старые открытые сообщения и резервные копии не шифруются задним числом; уже сохранённая локальная история остаётся открытой. После обновления старый открытый текст с сервера отображается как недоступный.

В этой версии используется общий ключ разговора, без отдельных подписей устройств и forward secrecy. Утечка ключа раскрывает сохранённую переписку, зашифрованную этим ключом. Потеря всех устройств и сохранённых кодов означает потерю доступа к зашифрованным сообщениям. Независимый аудит криптографического протокола не выполнялся.

### Файлы

- `poknite-0.2.0-linux-x64.tar.gz` — сервер и клиент для Ubuntu 24.04 x86_64.
- `poknite-0.2.0-windows-x64.zip` — клиент Windows 10/11 x64.
- `poknite-0.2.0-android.apk` — подписанный APK для Android 8 и новее.
- `poknite-0.2.0-android.zip` — APK, документация и лицензии.
- `SHA256SUMS` и `attestation.sigstore.json` — контрольные суммы и подтверждение происхождения сборок GitHub.

Windows EXE не подписан Authenticode. Порядок проверки подписей и контрольных сумм описан в [инструкции релизов](https://github.com/Veetver/Poknite/blob/v0.2.0/docs/releases.md#проверка-скачанного-релиза).
